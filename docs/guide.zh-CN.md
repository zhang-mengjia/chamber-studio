# Chamber Studio · 模块化实验箱

[English](../README.md) · [中文首页](../README.zh-CN.md)

本机使用的实验箱配置网页。双击 **启动网页.cmd**，然后在浏览器中操作。无需联网、账号或安装前端依赖。网页地址为 <http://127.0.0.1:47831>。

## 配置方式

1. 直接点击透视图或墙面正视图中的空白面板，在点击位置附近的弹窗中选择模块。没有独立墙面配置视图或设置侧栏。
2. 每列宽 2 单位，2×2 模块占两行，2×1 模块占一行。墙面使用连续的暖灰面板，安装格仅在启用网格时显示。点击已有模块，在就地弹窗中修改类型、状态和参数；再次点击当前类型不会重置参数。
3. 拖动模块可在同墙或左右墙之间移动，绿色框表示可放置，红色表示占位冲突或越界。抓取双行模块下半部时保留抓取位置。无效放置恢复原位。
4. 点击图中的大鼠调整朝向和大小，直接拖动改变位置；点击地板切换材质。顶部“大鼠”和“地板”按钮也可打开设置。大鼠面板提供站立、行走、后足直立、低头嗅探和坐姿五种缩略图，点击即可更换姿势，脚底位置保持稳定。
5. 选择透视图、正视图或布局说明图，然后通过顶部“导出图片 / PPT”保存。点击空白区域或按 Esc 可关闭设置。

## 快捷键与撤销

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Delete / Backspace | 删除选中模块，或隐藏选中大鼠 |
| Ctrl+C / Ctrl+X | 复制 / 剪切模块，包含全部状态与参数 |
| Ctrl+V | 粘贴到选中的空白位置，不覆盖已有模块 |
| 方向键 | 模块按安装格移动；大鼠移动 1 个绘图单位 |
| Shift+方向键 | 大鼠移动 10 个绘图单位 |
| Esc | 取消拖动或取消选择 |
| Ctrl+S | 下载配置文件 |

输入框中保留正常编辑快捷键。拖动、缩放、状态修改及删除均可撤销，连续拖动或缩放只计一次操作。最多保存 60 步撤销记录，刷新网页后重新开始记录。拖动过程中按 Esc 取消，其他编辑快捷键暂不执行。

| 模块 | 尺寸 | 状态与参数 |
| --- | --- | --- |
| 食槽 | 2×2 | 无食物 / 有食物；谷物、蔗糖、巧克力、香蕉、草莓 |
| 水槽 | 2×2 | 无水 / 有水；10、20、40、80、160 μL |

| 摄像头 | 2×1 | 关闭 / 录像 |

箱体采用参考图中的暖灰墙面、细黑轮廓和平面色块。原始 PPT 内嵌的 SVG 曲线已按箱体、灯体、孔阵喇叭、压杆和水杯拆分复用，其余设备按同一配色和线宽绘制。地板可选择平面地板、金属横杠或多孔亚克力。五种大鼠姿势已重绘成黑白毛色、淡粉皮肤的原生矢量，保留姿势和脚底锚点，可平移、等比缩放及左右翻转。参见[绘图风格与可编辑样例](illustration-style.md)。

## 保存与导出

- 自动保存：当前方案保存在此浏览器的本机存储中。清除浏览器数据会删除它，建议另存配置文件。
- 保存配置：下载 `.chamber.json`，以后使用“载入配置”继续修改。左右墙、模块参数、地板、大鼠和视图选项均随文件保存。
- PPT：原生 PowerPoint 自由曲线和文本。每个设备以组合形式保存，进入组合或取消组合可编辑内部零件。箱体、设备、地板和五种大鼠均为矢量对象，进入组合或取消组合即可编辑内部曲线和填色。
- PDF / SVG：箱体和大鼠保留矢量路径和文字，SVG 可脱离网页使用；单页尺寸与当前视图一致。
- PNG：可选裁紧后绘图尺寸的 1、2、3 倍，以及透明背景。常规箱体透视图为 608×608、1216×1216、1824×1824，保留原版方形外框。每面墙 3 列 8 排全部可安装；单排模块为 2:1，双排模块为 1:1，透视图按原版墙面坐标投影。
- 复制图片：顶部按钮将当前视图复制为 PNG，可直接粘贴到文档、PPT 或聊天窗口，沿用 PNG 分辨率和透明背景设置。浏览器需支持并允许剪贴板写入，网页需运行在 HTTPS 或 localhost 下。
- 所有图片、PDF 和 PPT 均按绘图边界裁紧。正视图与布局说明图保留比例；外部尺寸标注或箱体之外的大鼠会扩展边界，避免截断。
- 部件文字：绘图和所有导出均不添加部件名称、水量、口味、声音名称或频率说明；点击部件查看参数。旧配置即使启用了部件标注，也使用无部件文字的绘图方式。
- 闪烁：网页动态预览；静态导出使用点亮灯体，频率保存在配置文件中。
- 正视图展示两面墙，地板和大鼠仅在透视图及布局说明图中出现。

口味颜色、液面高度、声波和光晕用于图示区分。液面不按槽体的实际容积比例计算，声波不是真实音频，网页不控制实验设备。保存、载入配置和自动保存均保留所选姿势。旧版 stand、walk、rear、nose 设置对应新素材；旧版 press、eat 转换为 stand，其他装置配置保留。

## 运行与文件

启动脚本使用系统 Node.js 22 或以上。迁移至其他电脑时，复制整个项目目录并准备 Node.js 即可。关闭浏览器不会停止本地服务，可运行 `停止服务.ps1` 停止本项目服务。

```text
server.mjs              仅监听本机的静态文件服务
public/model.js         模块规格、状态、配置校验
public/scene.js         统一矢量场景与灯体结构
public/rat-art.js       LE 大鼠姿势素材与脚底锚点定位
public/geometry.js      墙面投影与安装位置点击区域
public/editor.js        原子移动、粘贴和撤销记录
public/app.js           就地弹窗、拖动与快捷键
public/i18n.js          中英文界面
public/export.js        PPT / PDF / PNG 导出
public/assets/          参考 SVG 原始曲线、大鼠矢量曲线、PPT 模板
public/vendor/          离线导出依赖和许可证
tests/model.test.mjs    尺寸、占位、状态及配置校验测试
```

开发检查：`npm test`。本项目无构建步骤，无远程资源依赖。在线版首次加载需联网；离线使用请下载完整项目并在本机启动。PPT 模板由 Artifact Tool 生成；导出时将统一场景写为原生 DrawingML。JSZip、pdf-lib 的许可证位于 `public/vendor/`。
