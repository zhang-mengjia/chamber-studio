- Assets: `rats/stand.png`, `rats/walk.png`, `rats/rear.png`, `rats/nose.png`, `rats/sit.png`.
- Provenance: five transparent PNGs supplied by the project owner from the 大鼠素材 directory, replacing the previous single vector rat. The supplied files were named `ChatGPT_图像_2026年10月12日_19_48_25-1.png` through `ChatGPT_图像_2026年10月12日_19_48_30-5.png`. Number 1 is walking, 2 rearing, 3 sniffing, 4 sitting and 5 standing.
- Preparation: PNG files are copied byte-for-byte. `rats/poses.json` records visible bounds, floor anchors and editor click outlines. Display and exports crop transparent margins without rewriting the original pixels, and use uniform scaling, translation and optional horizontal reflection. The previous 117-path asset is no longer used.
- Export: PPTX includes an editable picture object with the original PNG. PDF and SVG embed the original PNG alongside vector chamber geometry. Rat artwork is raster, so individual body parts are not editable vector curves.
